# 会议督办 AI Demo（航空港科创投资集团）

PC 端方案演示：上传 PDF / 转录稿 / 图片 → Agent 识别汇聚 → 整理待办 → 推送各位领导 → 看板跟踪。

原始需求见：[docs/原始需求-会议纪要与督查督办联动.md](docs/原始需求-会议纪要与督查督办联动.md)。

## 发给对方（推荐）

只发这一个文件，双击即可打开，不依赖其它文件、不需联网：

- **`会议督查督办系统.html`**

本地开发仍用 `index.html` + `styles.css` + `app.js`。若改过源文件，在本目录运行 `node pack-standalone.js` 可重新生成上述单文件。

## 打开方式

直接打开 **`index.html`**（单页，入口 / 办公室 / 领导都在同一文件内切换）。

- `#entry` 或无 hash — 选择身份
- `#office` — 办公室端
- `#leader` — 领导端

顶栏「切换身份」在页内切换，不必刷新。办公室推送后切到领导端即可看到红黄绿牌。

`office.html` / `leader.html` 会跳转到对应 hash，仅作兼容。

## 建议演示路径

1. 打开 `index.html` 选择「办公室端」→ 载入或上传材料 → Agent 识别 → 整理待办 → 按领导推送
2. 顶栏切换至领导端 → 红黄绿牌看板、提醒升级、督查周报、智能问答

Demo 数据存在浏览器 `localStorage`（`pm_meeting_demo_v4`），两端共用同一套数据。
