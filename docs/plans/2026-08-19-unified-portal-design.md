# 统一智能决策门户设计

**日期：** 2026-08-19  
**状态：** 已确认，进入实现

## 目标

为科创集团提供统一首页门户：顶栏三导航（投资决策 → 督查督办 → 安全生产）；后两个模块复用已有 demo，投资决策外跳既有系统。

## 结构

- 左侧：`portal/assets/logo.png` +「科创集团 | 智能决策门户」
- 中间：文字 Tab（白底面板风格，选中蓝下划线）—— 投资决策｜督查督办｜安全生产
- 右侧：数据已更新、消息铃铛、用户头像（静态演示）
- 顶栏视觉对齐安全生产看板面板：浅蓝描边、角标、`#0a4a86` 标题色、`#2f7de1` 强调色

## 交互

| 导航 | 行为 |
|------|------|
| 投资决策 | 本页 iframe 嵌入 `https://fde-demo.fineres.com:3000/` |
| 督查督办 | iframe 嵌入（隐藏原顶栏）；门户右侧切换办公室端 / 领导端 |
| 安全生产 | 本页 iframe 加载 `safety-production-demo/index.html`（**默认**） |

- URL hash：`#investment` / `#supervision` / `#safety`；默认 `#safety`
- 点「投资决策」先可写 hash，再外跳；返回门户时仍可从 hash 恢复其他模块
- iframe 实例保留，切换时显隐，避免重复加载

## 非目标

- 门户内不重做 KPI / 项目卡片 / AI 问答
- 不修改两个既有 demo 的业务逻辑

## 文件

```
portal/
  index.html
  styles.css
  app.js
```

本地需用静态 HTTP 服务打开（避免 `file://` 下 iframe 受限）。
