# 安全生产管理 Demo（框架页）

视觉：国内政务科技蓝大屏（浅蓝底、角标面板、ECharts 地图/趋势/专项/排名）。布局沿用投资分析参考图。

原始需求见：[docs/原始需求-安全生产管理.md](docs/原始需求-安全生产管理.md)

## 打开方式

- **对外发送：`安全生产看板.html`（一个文件，双击打开）**
- 开发用：`index.html`（上报已并入同一页，不再需要单独打开 report.html）

## 演示说明

本 Demo 为 **投资分析场景配套框架**，模拟数据、不实连数据库或低代码平台。具体能力（预警规则、月报正文、智能问答）可对着页面 **口头讲解**。

建议演示路径：

1. 打开 `index.html`，讲跨项目统一库、自动预警、看板、月报价值
2. 点左上角「安全隐患排查上报」（已并入同一页），提交后看板数字会变
3. 在条目里可点「整改完成，录入闭环」
4. 点地图 / 排名 / KPI 下钻；点「生成本月报告」与「智能问答」

对外发送：直接发 `安全生产看板.html` 一个文件即可（双击用浏览器打开）。图表仍需联网加载 ECharts。
